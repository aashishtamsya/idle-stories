# Idle Stories

A free-to-play mobile idle simulator with Indian business stories, built with Flutter.

- `AGENTS.md`: the standing brief for anyone working here.
- `PLAYBOOK.md`: the pipeline and the routine for each kind of request.
- `docs/art-guideline.md`: the agreed look.
- `docs/project-history.md`: research and decisions.

Work is tracked in GitHub Issues.
